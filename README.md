# astrbot_plugin_student_assistant

> 学院团学事务智能沟通小助手 —— 基于 AstrBot 原生知识库的学生自助问答与业务闭环插件。

## 设计定位

学生自助问答（综测、奖助、团务、办事流程等）**由 AstrBot 内置知识库（RAG）直接完成**，本插件不做问答本身，只补齐原生能力做不到的业务闭环，以"旁路监听"方式工作，不干扰原生问答体验。

## 功能

- **未答收集**：挂载 LLM 请求钩子，自动识别"知识库没答上来的学生提问"并记录，避免问题石沉大海。管理员可随时查看、标记处理
- **链接入库**：管理员在群内发送网页链接，自动抓取内容写入知识库，无需打开 WebUI 上传文件
- **知识库状态**：群内直接查看知识库配置是否正确、是否可用

## 工作原理

```
学生 @机器人 提问
        ↓
AstrBot 原生知识库检索并回答（插件不参与）
        ↓
[钩子] 本次 LLM 请求是否注入了知识库上下文？
   ├─ 是 → 正常回答，插件不做任何事
   └─ 否 → 消息像提问（含问号/疑问词）→ 记录到未答清单（同群同问题 24h 去重）
                ↓
        管理员 /未答列表 查看 → 补资料入库 → /未答解决
```

## 安装与前提

1. **AstrBot >= 4.5.0**（内置知识库功能）+ 已配置嵌入模型（推荐硅基流动 `BAAI/bge-m3`，免费）
2. 在 WebUI「知识库」页面创建知识库（如「团学事务知识库」）
3. 在 WebUI「配置文件 → AI 配置 → 能力 → 知识库」中勾选该知识库
4. 安装本插件：WebUI 插件页 GitHub 安装，填入本仓库地址；或 clone 到 `data/plugins/` 后重载
5. 在插件配置中填写知识库名称（需与 WebUI 中的名称完全一致）

## 配置项

| 配置项 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `kb_name` | string | 团学事务知识库 | 知识库名称，需与 WebUI 中完全一致 |
| `allowed_groups` | list | [] | 群白名单，留空则所有群生效 |
| `question_keywords` | list | ？/怎么/如何 等 | 判定"像提问"的关键词，未命中知识库且含关键词才记录 |
| `list_limit` | int | 20 | /未答列表 最多显示条数 |

## 指令（均限管理员）

| 指令 | 说明 |
|---|---|
| `/未答列表 [全部]` | 查看待处理的未答问题（默认本群，加"全部"看所有群） |
| `/未答解决 <编号>` | 标记某条问题已处理 |
| `/加入未答 <问题>` | 手动登记一条待补资料的问题 |
| `/加入知识库 <网页链接>` | 抓取网页内容入库（链接需可公开访问） |
| `/知识库状态` | 查看知识库配置与可用状态 |

## 数据存储

未答问题记录存于 `data/plugins_data/astrbot_plugin_student_assistant/assistant.db`（SQLite），升级/重装插件不丢失。

## 已知限制（MVP）

- 未答判定基于"是否注入知识库上下文"：知识库检索命中但内容答非所问时，不会计入未答清单
- AstrBot 配置中未启用知识库时，所有像提问的消息都会被记录（此时实际上没有 RAG 在回答）
- 链接入库依赖网页可公开访问，需登录的内部系统页面暂不支持
