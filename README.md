# astrbot_plugin_student_assistant

> 学院团学事务智能沟通小助手 —— 基于 AstrBot 原生知识库的学生自助问答与业务闭环插件。

## 设计定位

学生自助问答（综测、奖助、团务、办事流程等）**由 AstrBot 内置知识库（RAG）直接完成**，本插件不做问答本身，只补齐原生能力做不到的业务闭环，以"旁路监听"方式工作，不干扰原生问答体验。

**群聊与私聊（单聊）均可用**：学生可以单独私聊机器人提问，私聊数据以 `private:<用户ID>` 归档，与群聊数据互相隔离。

覆盖榜题四条诉求的分工：

| 诉求 | 由谁完成 |
|---|---|
| 学生自助问答 | AstrBot 原生知识库（RAG） |
| 无人解答的问题汇总并转给工作人员 | 插件 · 模块 A：未答收集 + 实时推送 |
| 沟通摘要 | 插件 · 模块 B：群聊整理 |
| 待办清单 + 自动同步 | 插件 · 模块 C：待办管理 |

## 功能

### 模块 A · 未答收集、实时推送与解答学会

- **未答收集**：挂载 LLM 请求钩子，自动识别"知识库没答上来的学生提问"（群聊与私聊均生效），避免问题石沉大海
- **实时推送**：负责人发送 `/开启未答推送` 订阅后，新未答问题会实时推送到该会话（推荐私聊订阅；官方机器人平台受主动消息配额限制，推送失败自动跳过）
- **解答学会**：`/未答解决 <编号> <标准答案>` 在处理问题的同时把答案登记为 FAQ；之后学生提出**相似问题**（2-gram 相似度 ≥ 0.4 或完全一致），插件会把标准解答注入 LLM 请求，实现"问过一次，下次就会"
- **链接入库**：管理员发送网页链接，自动抓取内容写入知识库，无需打开 WebUI 上传文件
- **知识库状态**：直接查看知识库配置是否正确、是否可用

### 模块 B · 群聊整理（沟通摘要）

- 管理员发送 `/整理`，AI 回溯近期群聊（优先拉 OneBot 历史消息，QQ 官方机器人使用插件实时缓存），提炼一份**沟通摘要**；私聊中支持引用消息整理
- 摘要中识别出的**待办事项**自动登记进待办清单（同会话同内容 24h 内去重），无需手动逐条记录

### 模块 C · 待办管理与同步播报

- 待办清单独立管理（群聊按群隔离、私聊按人隔离）：手动记、AI 从引用消息提取、列表查看、完成、删除
- `/同步待办` 生成播报文案，支持**语气自适应**：面向老师正式得体、面向同学轻松亲切（AI 改写失败自动退回纯文本清单，保证可用）
- 可选自动播报：登记新待办后立即在群内提醒（默认关闭）

## 工作原理

```
学生私聊 / 群内 @机器人 提问
        ↓
AstrBot 原生知识库检索并回答（插件不参与）
   ↑ 插件旁路增强：命中已学会的问答（FAQ）时，把标准解答注入请求
        ↓
[钩子] 本次 LLM 请求是否注入了知识库上下文？
   ├─ 是 → 正常回答，插件不做任何事
   └─ 否（且未命中 FAQ）→ 消息像提问（含问号/疑问词）
                ↓
        记录到未答清单（同会话同问题 24h 去重）
                ↓
        实时推送给已订阅的负责人会话（/开启未答推送）
                ↓
        负责人 /未答解决 <编号> <标准答案> → 标记处理 + 登记为 FAQ
                ↓
        下次相似问题 → 自动带上该解答回答（"问过一次，下次就会"）

群内日常沟通（所有文本消息实时缓存，供官方机器人回溯）
        ↓
管理员 /整理（可引用某条消息，否则回溯最近 N 条）
        ↓
AI 提炼摘要 + 识别待办 → 待办自动入清单（去重）→ 群内输出摘要
        ↓
/同步待办 [老师] → 按对象生成播报文案 → 转发/复制给对应的人
```

## 安装与前提

1. **AstrBot >= 4.5.0**（内置知识库功能）+ 已配置嵌入模型（推荐硅基流动 `BAAI/bge-m3`，免费）
2. 在 WebUI「知识库」页面创建知识库（如「团学事务知识库」）
3. 在 WebUI「配置文件 → AI 配置 → 能力 → 知识库」中勾选该知识库
4. 安装本插件：WebUI 插件页 GitHub 安装，填入本仓库地址；或 clone 到 `data/plugins/` 后重载
5. 在插件配置中填写知识库名称（需与 WebUI 中的名称完全一致）

> 未答收集、知识库指令需要知识库；模块 B/C 的 `/整理`、待办指令不依赖知识库，只要配好 LLM 即可使用。

## 配置项

| 配置项 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `kb_name` | string | 团学事务知识库 | 知识库名称，需与 WebUI 中完全一致 |
| `allowed_groups` | list | [] | 群白名单，留空则所有群生效 |
| `question_keywords` | list | ？/怎么/如何 等 | 判定"像提问"的关键词，未命中知识库且含关键词才记录 |
| `list_limit` | int | 20 | /未答列表 最多显示条数 |
| `summary_count` | int | 30 | /整理 未引用消息时回溯的群聊条数，建议 20~50 |
| `auto_sync` | bool | false | 登记新待办后是否立即在群内播报提醒 |

## 指令（均限管理员、群聊与私聊均可）

| 指令 | 说明 |
|---|---|
| `/未答列表 [全部]` | 查看待处理的未答问题（群聊默认本群，私聊默认全部，加"全部"看所有会话） |
| `/未答解决 <编号> [标准答案]` | 标记某条问题已处理；**附上标准答案会被记住**，下次相似问题自动参考回答 |
| `/问答列表` | 查看已学会的问答（FAQ） |
| `/删问答 <编号>` | 删除一条学错的问答 |
| `/加入未答 <问题>` | 手动登记一条待补资料的问题 |
| `/开启未答推送` | 订阅未答问题实时推送（推荐负责人私聊使用） |
| `/关闭未答推送` | 取消订阅未答推送 |
| `/加入知识库 <网页链接>` | 抓取网页内容入库（链接需可公开访问） |
| `/知识库状态` | 查看知识库配置与可用状态 |
| `/整理` | AI 回溯群聊生成沟通摘要，并自动登记识别出的待办；引用某条消息则只分析该消息（私聊仅支持引用消息） |
| `/记待办 <文字>` 或 引用消息 + `/记待办` | 手动或让 AI 从引用内容中提取待办并登记 |
| `/待办列表 [全部]` | 查看待办清单（默认本群/私聊本人的） |
| `/完成待办 <编号>` | 标记待办完成 |
| `/删待办 <编号>` | 删除待办 |
| `/同步待办 [老师]` | 生成同步播报文案（默认同学语气，加"老师"切换正式语气） |

## 数据存储

未答问题、问答（FAQ）、待办、推送订阅、群消息缓存均存于 `data/plugins_data/astrbot_plugin_student_assistant/assistant.db`（SQLite），升级/重装插件不丢失。

- 群聊数据按群号归档，私聊数据按 `private:<用户ID>` 归档，互不串扰
- 群消息缓存每群保留 200 条 / 48 小时（先到为准），仅为 QQ 官方机器人无法拉取历史消息兜底
- 同会话同内容的待办 24h 内自动去重，避免 `/整理` 重复登记

## 已知限制

- 未答判定基于"是否注入知识库上下文"：知识库检索命中但内容答非所问时，不会计入未答清单；AstrBot 配置中未启用知识库时，所有像提问的消息都会被记录
- FAQ 相似匹配基于文本 2-gram 相似度（阈值 0.4），问法差异过大时不会命中，此时问题会照常进入未答清单，由负责人再次解答（答案规范化后 q_norm 相同则覆盖更新）
- 实时推送依赖 `context.send_message`：QQ 官方机器人主动私聊受平台配额限制，推送失败自动跳过并记日志；NapCat（OneBot）平台无限制
- 链接入库依赖网页可公开访问，需登录的内部系统页面暂不支持
- 待办同步为**群内播报**：QQ 官方机器人无法精确私发到具体成员，且主动消息受平台配额限制，实际转发需人工完成
- AI 提取的截止时间会做格式校验，非法值自动丢弃（宁缺毋滥）；AI 输出异常时摘要退化为纯文本、播报退化为纯文本清单
- 群消息缓存仅存文本消息，图片/文件等内容不参与摘要
